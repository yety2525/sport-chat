# 🏆 SPORT CHAT V2.4

Aplicación de escritorio desarrollada en **Python** para consultar, comparar y visualizar información de deportistas.

El proyecto utiliza una interfaz gráfica creada con **Tkinter** y permite trabajar con información e imágenes de atletas, ofreciendo una experiencia sencilla y visual para explorar el mundo deportivo.

---

## 🚀 Características

* 🏋️ Consulta de información de deportistas.
* ⚔️ Comparación entre atletas.
* 🖼️ Visualización de fotografías de los deportistas.
* 💬 Interfaz gráfica desarrollada con Tkinter.
* 🌐 Obtención de información mediante solicitudes HTTP.
* 🐍 Desarrollado completamente en Python.
* 🎨 Interfaz moderna con tema oscuro.
* 📊 Información organizada para facilitar la comparación.

## 💻 Requisitos

Para ejecutar el proyecto necesitas:

* Python 3.x
* conexión a Internet
* las siguientes librerías:

```bash
pip install requests pillow
```

> Tkinter normalmente viene incluido con las instalaciones de Python para Windows.

---

## ▶️ Cómo ejecutar el proyecto

### 1. Clonar el repositorio

```bash
git clone https://github.com/yety2525/sport-chat.git
```

### 2. Entrar en la carpeta

```bash
cd sport-chat
```

### 3. Instalar las dependencias

```bash
pip install requests pillow
```

### 4. Ejecutar la aplicación

```bash
python sportchat.py
```
